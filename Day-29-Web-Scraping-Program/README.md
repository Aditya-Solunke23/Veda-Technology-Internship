# Day 29 – Web Scraping Program

## Overview
A Python web scraper that extracts publicly available book information
from Books to Scrape and exports the results to a CSV file.

## Features
- Retrieves webpage HTML using HTTP requests
- Parses HTML using BeautifulSoup
- Extracts book titles, prices, ratings, and availability
- Saves extracted records to CSV
- Handles HTTP and connection errors
- Displays sample extracted records in the terminal

## Technologies Used
- Python 3
- Requests
- BeautifulSoup
- CSV module
