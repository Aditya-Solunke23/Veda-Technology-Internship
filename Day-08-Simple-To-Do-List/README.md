# Day 8 - Simple To-Do List

## Project Description

This project is a simple command-line To-Do List application built using Python.

The program allows users to add, view, update, and remove tasks through a menu-driven interface.

## Objective

The objective of this task is to practice:

- Lists
- Loops
- Conditional statements
- Functions
- User input
- Menu-driven programs
- Basic CRUD operations
- Input validation

## Features

- Add new tasks
- View existing tasks
- Update tasks
- Remove tasks
- Handle invalid menu choices
- Handle invalid task numbers
- Prevent empty tasks from being added

## CRUD Operations

CRUD stands for:

- **Create** - Add a new task
- **Read** - View existing tasks
- **Update** - Modify an existing task
- **Delete** - Remove a task

## How It Works

1. The program displays a menu containing different operations.
2. The user selects an option.
3. The selected function is executed.
4. Tasks are stored in a Python list.
5. The menu continues to appear until the user selects Exit.
