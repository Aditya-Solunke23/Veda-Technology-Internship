# Personal Expense & Budget Tracker

A Python-based Personal Expense Tracker developed as part of my Veda Technology Python Programming Internship.

## Day 40 – Project Day 1: Expense Management System

### Project Overview

The first phase focuses on developing a basic expense management application that allows users to record, view, edit, and delete their daily expenses.

### Features Implemented

- Add new expenses.
- View all recorded expenses.
- Edit existing expense records.
- Delete expenses with confirmation.
- Validate expense amounts.
- Validate dates using Python datetime.
- Organize expenses using predefined categories.
- Generate unique expense IDs.
- Store expense records in JSON format.

### Technologies Used
