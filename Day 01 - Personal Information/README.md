# Personal Information Program

## Task 1 - Python Programming Track

This project is a simple Python program that accepts basic information from a user and displays it in a clean, formatted profile.

## Objective

The objective of this project is to understand and practice:

- Python variables
- `input()`
- `print()`
- Type conversion
- Integer data type
- Strings
- f-strings
- Formatted output

## Features

The program accepts the following information:

- Full Name
- Age
- City
- College
- Course
- Email Address

After collecting the information, the program displays it as a formatted personal profile.

## Technologies Used

- Python 3
- Visual Studio Code
