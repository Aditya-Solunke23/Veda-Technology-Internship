# Day 6 - Multiplication Table

## Project Description

This project is a simple Python program that accepts a number and a specified limit from the user and generates its multiplication table up to that limit.

## Objective

The objective of this task is to practice:

- `for` loops
- `range()`
- User input
- Type conversion
- Arithmetic operations
- Formatted output
- Input validation

## Features

- Accepts a number from the user
- Allows the user to specify the table limit
- Generates the multiplication table using a `for` loop
- Displays the results in a clear format
- Validates the table limit

## How It Works

1. The user enters a number.
2. The user enters the required table limit.
3. The program validates that the limit is greater than 0.
4. A `for` loop is used to generate the multiplication table.
5. Each multiplication result is displayed using formatted output.
