# Day 33 – Python Project With Logging

## Overview
A simple Student Records Manager that uses Python's logging module
to record application events and errors.

## Features
- Add student records
- View student records
- Calculate grades
- Detect duplicate student IDs
- Validate student names and marks
- Record application events in a log file

## Technologies Used
- Python 3
- logging module

## Logging Levels Demonstrated
- INFO: Successful application events
- WARNING: Duplicate student IDs or missing records
- ERROR: Invalid input or failed operations

## How to Run

```bash
python student_manager.py
