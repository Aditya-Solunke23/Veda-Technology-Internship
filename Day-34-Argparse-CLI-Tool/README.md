# Day 34 – Python Command-Line Tool with argparse

## Overview
A command-line password generator that accepts arguments and options
using Python's argparse module.

## Features
- Configurable password length
- Lowercase letter option
- Uppercase letter option
- Digit option
- Special character option
- Secure password generation using secrets
- Built-in help command
- Argument validation

## Technologies Used
- Python 3
- argparse
- secrets
- string

## How to Run

Generate a default password:

```bash
python password_cli.py
