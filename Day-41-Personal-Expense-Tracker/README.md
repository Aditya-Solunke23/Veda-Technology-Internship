# Personal Expense & Budget Tracker

A Python-based Personal Expense & Budget Tracker developed as part of my Veda Technology Python Programming Internship.

## Day 41 – Project Day 2: Category Management, Search & Filtering

### Project Overview

The second phase focuses on improving the expense management application by introducing category-based organization, keyword searching, and advanced filtering options.

### Features Implemented

**Existing Day 1 Features:**
- Add, view, edit, and delete expenses.
- Validate expense amounts and dates.
- Generate unique expense IDs.
- Store records using JSON.

**New Day 2 Features:**
- Display predefined expense categories.
- Search expenses by description.
- Filter expenses by category.
- Filter expenses by transaction date.
- Filter expenses by minimum and maximum amount.
- Combine multiple filters using advanced filtering.
- Display matching records and their total amount.
- Validate search and filter inputs.
