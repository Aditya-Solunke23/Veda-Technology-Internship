# Day 12 - Palindrome Checker

## 📌 Project Description

A simple Python program that checks whether a word or sentence is a palindrome.

The program normalizes the input by converting it to lowercase and removing unnecessary spaces before comparing the original and reversed text.

## 🎯 Objective

The objective of this task is to practice string manipulation, string slicing, and comparison logic in Python.

## 🛠️ Technology Used

- Python

## ✨ Features

- Accepts a word or sentence from the user
- Ignores capitalization
- Ignores spaces
- Reverses strings using slicing
- Determines whether the input is a palindrome
- Handles empty input
- Displays the normalized text and result

## 🧠 Concepts Practiced

- Strings
- `input()`
- `lower()`
- `split()`
- `join()`
- String slicing
- String comparison
- Conditional statements
