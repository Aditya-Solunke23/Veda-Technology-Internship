# Day 26 – Date and Time Utility

## Overview
A Python application that performs common date and time calculations using
Python's built-in datetime module.

## Features
- Calculate age from a birth date
- Calculate the difference between two dates
- Count working days, excluding weekends
- Format dates into readable strings
- Add days to a date
- Display the current date and time
- Calculate the difference between two datetime values
- Validate date input and handle errors

## Technologies Used
- Python 3
- datetime module

## Project Structure
- `date_time_utility.py` – Reusable date and time functions
- `main.py` – Interactive menu-driven application
- `README.md` – Project documentation
- `sample_output.txt` – Example terminal output

## How to Run
1. Install Python 3.
2. Open a terminal in the project directory.
3. Run:

   ```bash
   python main.py
