# Day 11 - Word and Character Counter

## 📌 Project Description

A simple Python text analysis program that accepts a paragraph from the user and calculates the number of characters, words, sentences, and spaces.

## 🎯 Objective

The objective of this task is to practice string manipulation and basic text processing in Python.

## 🛠️ Technologies Used

- Python

## ✨ Features

- Accepts a paragraph from the user
- Counts total characters
- Counts words using `split()`
- Counts sentences using `.`, `!`, and `?`
- Counts spaces
- Handles empty input
- Displays formatted text statistics

## 🧠 Concepts Practiced

- Strings
- `input()`
- `len()`
- `split()`
- `count()`
- `for` loops
- Conditional statements
- String manipulation
- Basic text processing

## ▶️ How to Run

Open a terminal in the project folder and run:

```bash
python text_counter.py
