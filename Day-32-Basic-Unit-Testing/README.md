# Day 32 – Basic Unit Testing Project

## Overview
A simple Python calculator project with automated unit tests
for its main functions.

## Features
- Addition
- Subtraction
- Multiplication
- Division
- Even number checking
- Number squaring
- Automated tests for valid and invalid cases

## Technologies Used
- Python 3
- unittest

## Project Structure

- `calculator.py` – contains the functions being tested
- `test_calculator.py` – contains automated unit tests
- `sample_output.txt` – sample test execution results

## How to Run Tests

Open a terminal in this folder and run:

```bash
python -m unittest -v
