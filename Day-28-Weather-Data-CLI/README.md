# Day 28 – Weather Data CLI

## Overview
A command-line weather application that retrieves current weather
information for a user-provided city.

## Features
- Search for a city by name
- Retrieve geographic coordinates
- Fetch current weather data
- Display temperature and feels-like temperature
- Show humidity, wind speed, and precipitation
- Convert weather codes into readable descriptions
- Handle invalid city names and API errors

## Technologies Used
- Python 3
- Requests library
- Open-Meteo Geocoding API
- Open-Meteo Weather API
- JSON
