# Day 9 - Student Records Using Lists

## Project Description

This project is a Python program that stores student names and their corresponding marks using lists.

The program performs different list-processing operations such as displaying student records, searching for a student, sorting students according to their marks, and finding the highest and lowest scores.

## Objective

The objective of this task is to develop practical skills in processing Python lists.

## Features

- Stores student names and marks in lists
- Displays all student records
- Searches for a student by name
- Finds the highest score
- Finds the lowest score
- Sorts students according to their marks
- Handles students that are not found
